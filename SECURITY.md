# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or a bypass in EOL-PHP-Armor:
1. Please do **NOT** open a public issue.
2. Email the maintainer directly at: `55404783+Anton-Barinov@users.noreply.github.com` or create a private GitHub Security Advisory.
3. Include clear reproduction steps, request headers, and payload.

We take all reports seriously and aim to release patches or mitigation rules within 24 hours.
